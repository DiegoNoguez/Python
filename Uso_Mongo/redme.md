# Acerca de este directorio / About this directory

En el presente directorio del repositorio de python se estará manejando o mostrando la manera de como trabjar python con la Base de Datos no relacional, es decir se trabajara con el modelo NoSQL y como motor o gestro NoSQL usaremos al mas conocido MongoDB 

Así como tambien tenemos que tener en cuento que a diferencia de lo que es SQL y sus propios ORM para mongo no existe algo así sino mas bien se centra en el uso de librerias como el nombre que tiene este directorio de pymongo sin embargo esta libreria solo se encarga de hacer conexiones y procesos directos. Mas sin en cambio, Pymongo tambien se complementa con la libreria de Pydantic ya que esta nos permite crear Schemas.
